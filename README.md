# Network Note

A non-linear cross-platform personal note-taking app.

## Dependency
1. Sembast for NoSQL.
2. path_provider

## Features and Plans

### Planned Features
1. Store notes data as JSON.
2. Each note can link to another notes as many as possible.
3. When viewing a note, each click on a linked note put the clicked note to below the former note. (Like Tiddlywiki)
4. Markdown syntax support.
5. Can save to GDrive and Dropbox.

### Minimum Viable Product Stages
1. CRUD for notes
2. Note linking and linked note viewing.
3. Markdown support.
4. Export and backup to online services (GDrive and Dropbox).
5. Possible: Use with Firebase/Firestore.
